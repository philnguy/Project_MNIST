# Project_MNIST

- This project explores the cluster structure of the Ethiopic MNIST dataset, which
contains grayscale images of handwritten Ge’ez numerals.
- This project demonstrates how I approach real-world data analysis. From
raw data, to cleaning and transforming it, to exploring the structure, and generating
insights.
- The goal wasn’t to build a predictive model, but to analyze a complex dataset and
understand its structure. I focused on comparing analytical approaches and
understanding ambiguity in the data.
